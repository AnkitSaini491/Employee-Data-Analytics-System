# Employee-Data-Analytics-System
A Python-based employee data analytics project using Pandas and Matplotlib.
Employee Data Analytics System

A Python-based data analytics project that analyzes employee information such as salary, department, experience, performance, and attrition.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

Features

- Employee data analysis
- Department-wise employee analysis
- Average salary analysis
- Experience analysis
- Employee performance analysis
- Attrition analysis
- Data visualization
- Automated analytics report

Project Structure

Employee-Data-Analytics-System/
│
├── employee_data_analytics.py
├── employee_data.csv
└── README.md

How to Run

Install required libraries:

pip install pandas numpy matplotlib

Run the project:

python employee_data_analytics.py

Output

The project generates:

- Average salary by department
- Employee distribution by department
- Experience vs salary analysis
- Performance analysis
- Attrition statistics
- Final employee analytics report
